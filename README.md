# ENDLESS DUNGEON

3Dダンジョンを、パーティが自動で延々と歩き続けるのを眺めるアプリ。そのまま MP4 に書き出せる。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 画面比率は 4:3 / 16:9
- 迷宮の見た目
  - 線画（線の色は白・緑・琥珀・水色）
  - テクスチャ8種（石の回廊・赤レンガ・苔むした遺跡・木の砦・洞窟・鉄の迷宮・氷の洞・魔界）
  - 階ごとに変わるモード
- 画面の飾り（あり/なし）
  - あり：枠・自動で描かれる地図・パーティの表・メッセージ欄
  - 遭遇・宝箱・扉・行き止まりなどのメッセージが出る
- 画素の粗さ（なめらか / 粗い / とても粗い）、見通し（近い / ふつう / 遠い）
- 歩き方（なめらか / 1マスずつ）、速さ3段階
- 迷宮の番号（シード）
  - 同じ番号・同じ歩き方なら、毎回同じ道のりになる
- MP4書き出し
  - 大きさ：640×480〜1920×1080
  - 長さ：「3:19」のように分:秒で指定（ただの数字なら分）
  - 30 / 60コマ/秒
  - 歌詞：曲（.m4a など）に字幕トラックとして入っている歌詞、または .lrc / .srt / .vtt を、飾りありならメッセージ欄、なしなら画面下の字幕として曲に合わせて流す
  - 音：MP3・M4A・WAV などを入れると音付きで書き出す（長さは曲に合わせる。長くすると繰り返し、最後の1.5秒で音をしぼる）

## しくみのメモ

- **迷宮**：12×12マスの区画をその場で生成して無限に並べる。
  - 区画の中は穴掘り法でひとつながりにし、壁を少し抜いて回り道を作り、部屋と扉を置く。
  - 各区画から東と南の隣へ必ず出入口を開けるので、全体が必ずつながる。
  - 壁はマスの辺に置く方式（Wizardry と同じ「薄い壁」）。
- **歩き方**：まだ行っていない一番近いマスへ幅優先探索で向かう。
  - 前→左右→後ろの順で探すので、通路はまっすぐ進みがち。
  - 1階につき 90〜250歩 ほど歩いたら、見つけた下り階段へ向かって降りる。
  - 30分歩かせて12階ほど。
- **描画**：WebGL2。
  - 線画は、壁を黒く塗りつぶしたうえで縁だけを線にしているので、奥の線が手前の壁で正しく隠れる。
  - テクスチャはすべて 64×64 をその場で描いている（画像ファイルなし）。
- **書き出し**：WebCodecs（H.264）と [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.1.3 を使う（同梱）。
  - 実時間より速く1コマずつ描いて符号化する。手元では 1440×1080・30コマで、12秒の動画を約1.6秒で書き出せた。
  - Chrome / Edge では保存先を先に選ばせ、ファイルへ直接書き込む（長い動画でもメモリを食わない）。
  - それ以外のブラウザではメモリ上で作ってからダウンロードする。
  - 音は48kHzで読み込み（ブラウザが読めない Opus 入りの .m4a は、MP4 を自分で解いて同梱の [opus-decoder](https://github.com/eshaz/wasm-audio-decoders) 0.7.11 で解く。Safari／Mac 標準の解読はこれに非対応）、AAC（無理なら Opus）にして映像のコマに追いつくぶんずつ混ぜて書く。
- ローカル確認：`python3 -m http.server 8799`
